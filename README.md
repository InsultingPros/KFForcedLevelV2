# KFForcedLevelV2

[![GitHub all releases](https://img.shields.io/github/downloads/InsultingPros/KFForcedLevelV2/total)](https://github.com/InsultingPros/KFForcedLevelV2/releases)

## General Information

Changes to original:

- Changed code formatting.
- Faster `tick()`.
- Added `GetDescriptionText()` to prevent log spam.

Configuragtion:

- `ForceTo` - the target perk level.
- `ForceWay` - how to force the levels. Available variants are `Min`, `Max`, `Only`.

## Installation

```bash
KFForcedLevelV2.ForcedLevelMut
```

## Building and Dependancies

Use [KF Compile Tool](https://github.com/InsultingPros/KFCompileTool) for easy compilation.

```Bash
EditPackages=KFForcedLevelV2
```
